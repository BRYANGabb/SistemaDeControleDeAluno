**Sistema de Controle de Aluno**

🔧 Funcionalidades

Cadastrar alunos (nome e duas notas)

Listar alunos cadastrados

Calcular e exibir a média de cada aluno

Mostrar a situação do aluno:

Aprovado

Recuperação

Reprovado

Menu interativo no console

💻 Tecnologias Utilizadas

Java

Scanner (entrada de dados)

Vetores (arrays)

🎯 Objetivo

Projeto criado para fins de aprendizado, servindo como base para evolução futura em Programação Orientada a Objetos (POO).
